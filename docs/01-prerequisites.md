## 第一步：检查能力

请先让自己的 Grok Bot 确认：
- 能否运行 Python 和安装依赖。
- 能否持久保存配置、任务状态和程序文件。
- 能否创建带鉴权的外部任务入口，并读取请求数据。
- 任务完成后能否运行回复程序，或访问独立桥接服务的受保护回传入口。
- 能否查看 Routine 运行记录和失败信息。
- 长时间运行的进程会不会因休眠、更新、重建或配额中断。

拿不到任务入口或回传能力时，先停止接入配置，选择平台明确支持的替代方案。普通 Grok API 的文本生成调用不能自动代替具有执行工具的 Grok Bot Routine。

## 部署位置

| 候选位置 | 需要确认 |
| --- | --- |
| 平台云端电脑 | 后台进程、持久文件、更新恢复、网络限制 |
| VPS | Python、出站网络、服务管理、平台任务入口 |
| 自己的常开设备 | 休眠设置、网络、进程恢复、状态存储 |

仅采用长轮询架构时，桥接设备不需要公网入站端口。若另加远程回传服务器，需要单独设计该入口的网络与鉴权。

## 成功标准

助手给出实际能力检查结果和明确部署方案；缺项写清楚，不以“应该可以”当作已验证。
